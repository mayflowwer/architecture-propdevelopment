# Требования к безопасности PropDevelopment
# Интеграция системы управления доступом (умный шлагбаум)

## 1. Общие положения

### 1.1 Область применения
Настоящие требования применяются ко всем контрагентам PropDevelopment, интегрирующим системы управления парковочным доступом (умные шлагбаумы), включая:
- Передачу номеров транспортных средств для верификации доступа
- Получение команд на открытие/закрытие шлагбаума
- Передачу событий доступа (въезд/выезд транспортных средств)
- Синхронизацию списков авторизованных транспортных средств

### 1.2 Юридическая основа
Для начала работы с PropDevelopment контрагент обязан:
1. Заключить договор с PropDevelopment на оказание услуг интеграции системы управления доступом
2. Заключить Соглашение об обработке персональных данных (DPA — Data Processing Agreement), которое определяет:
   - Правила обработки номеров транспортных средств как персональных данных
   - Меры защиты информации
   - Ответственность контрагента за нарушения
   - Процедуры уведомления об инцидентах информационной безопасности

### 1.3 Персональные данные
**ВАЖНО:** Номер транспортного средства является персональными данными согласно:
- **152-ФЗ "О персональных данных"** (Российская Федерация)
- **GDPR Article 4(1)** (Европейский Союз)
- **CCPA** (California, USA)

Обработка номеров автомобилей требует:
- Согласия владельца транспортного средства
- Уведомления о целях обработки и сроках хранения
- Обеспечения мер защиты информации
- Права на удаление данных по запросу

## 2. Аутентификация через API Key

### 2.1 Получение API Key

#### 2.1.1 Процедура выдачи
После заключения договора PropDevelopment выдает контрагенту уникальный API Key:

1. Контрагент подает заявку на получение API Key через защищенный портал PropDevelopment или по электронной почте
2. PropDevelopment генерирует уникальный API Key (256-bit криптостойкий случайный ключ)
3. API Key передается контрагенту **один раз** через защищенный канал:
   - Защищенный портал с аутентификацией
   - Email с PGP шифрованием
   - Личная передача уполномоченному представителю
4. PropDevelopment НЕ сохраняет API Key в открытом виде (только SHA-256 hash)
